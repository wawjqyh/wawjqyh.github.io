git ​

1、新建代码库 ​

1、在当前目录新建一个Git代码库

javascript
$ git init
1

2、新建一个目录，将其初始化为Git代码库

javascript
$ git init [project-name]
1

3、下载一个项目和它的整个代码历史

javascript
$ git clone [url]
1

2、配置 ​

Git的设置文件为.gitconfig，它可以在用户主目录下（全局配置），也可以在项目目录下（项目配置）。

1、显示当前的Git配置

javascript
$ git config --list
1

2、编辑Git配置文件

javascript
$ git config -e [--global]
1

3、设置提交代码时的用户信息

javascript
$ git config [--global] user.name "[name]"
$ git config [--global] user.email "[email address]"
1
2

3、增加/删除文件 ​

1、添加指定文件到暂存区

javascript
$ git add [file1] [file2] ...
1

2、添加指定目录到暂存区，包括子目录

javascript
$ git add [dir]
1

3、添加当前目录的所有文件到暂存区

javascript
$ git add .
1

添加每个变化前，都会要求确认

4、对于同一个文件的多处变化，可以实现分次提交

javascript
$ git add -p
1

5、删除工作区文件，并且将这次删除放入暂存区

javascript
$ git rm [file1] [file2] ...
1

6、停止追踪指定文件，但该文件会保留在工作区

javascript
$ git rm --cached [file]
1

7、改名文件，并且将这个改名放入暂存区

javascript
$ git mv [file-original] [file-renamed]
1

4、代码提交 ​

1、提交暂存区到仓库区

javascript
$ git commit -m [message]
1

2、提交暂存区的指定文件到仓库区

javascript
$ git commit [file1] [file2] ... -m [message]
1

3、提交工作区自上次commit之后的变化，直接到仓库区

javascript
$ git commit -a
1

4、提交时显示所有diff信息

javascript
$ git commit -v
1

5、使用一次新的commit，替代上一次提交

如果代码没有任何新变化，则用来改写上一次commit的提交信息

javascript
$ git commit --amend -m [message]
1

6、重做上一次commit，并包括指定文件的新变化

javascript
$ git commit --amend [file1] [file2] ...
1

5、分支 ​

1、列出所有本地分支

javascript
$ git branch
1

2、列出所有远程分支

javascript
$ git branch -r
1

3、列出所有本地分支和远程分支

javascript
$ git branch -a
1

4、新建一个分支，但依然停留在当前分支

javascript
$ git branch [branch-name]
1

5、新建一个分支，并切换到该分支

javascript
$ git checkout -b [branch]
1

6、新建一个分支，指向指定commit

javascript
$ git branch [branch] [commit]
1

7、新建一个分支，与指定的远程分支建立追踪关系

javascript
$ git branch --track [branch] [remote-branch]
1

8、切换到指定分支，并更新工作区

javascript
$ git checkout [branch-name]
1

9、切换到上一个分支

javascript
$ git checkout -
1

10、建立追踪关系，在现有分支与指定的远程分支之间

javascript
$ git branch --set-upstream [branch] [remote-branch]
1

11、合并指定分支到当前分支

javascript
$ git merge [branch]
1

12、选择一个commit，合并进当前分支

javascript
$ git cherry-pick [commit]
1

13、删除分支

javascript
$ git branch -d [branch-name]
1

14、删除远程分支

javascript
$ git push origin --delete [branch-name]
$ git branch -dr [remote/branch]
1
2

15、推送本地分支到远程

javascript
$ git push origin local_branch:remote_branch
1

7、查看信息 ​

1、显示有变更的文件

javascript
$ git status
1

2、显示当前分支的版本历史

javascript
$ git log
1

3、显示commit历史，以及每次commit发生变更的文件

javascript
$ git log --stat
1

4、搜索提交历史，根据关键词

javascript
$ git log -S [keyword]
1

5、显示某个commit之后的所有变动，每个commit占据一行

javascript
$ git log [tag] HEAD --pretty=format:%s

6、显示某个commit之后的所有变动，其"提交说明"必须符合搜索条件

javascript

7、显示某个文件的版本历史，包括文件改名

javascript

15、显示两次提交之间的差异

8、远程同步 ​

[remote]是远程仓库的名称，默认名称为origin

1、下载远程仓库的所有变动

javascript
$ git fetch [remote]
1

2、显示所有远程仓库

javascript
$ git remote -v
1

3、显示某个远程仓库的信息

javascript
$ git remote show [remote]
1

4、增加一个新的远程仓库，并命名

javascript
$ git remote add [shortname] [url]
1

5、取回远程仓库的变化，并与本地分支合并

javascript
$ git pull [remote] [branch]
1

6、上传本地指定分支到远程仓库

javascript
$ git push [remote] [branch]
1

6、强行推送当前分支到远程仓库，即使有冲突

javascript
$ git push [remote] --force
1

7、推送所有分支到远程仓库

javascript
$ git push [remote] --all
1

9、撤销 ​

1、恢复暂存区的指定文件到工作区

javascript
$ git checkout [file]
1

2、恢复某个commit的指定文件到暂存区和工作区

javascript
$ git checkout [commit] [file]
1

3、恢复暂存区的所有文件到工作区

javascript
$ git checkout .
1

4、重置暂存区的指定文件，与上一次commit保持一致，但工作区不变

javascript
$ git reset [file]
1

5、重置暂存区与工作区，与上一次commit保持一致

javascript
$ git reset --hard
1

6、重置当前分支的指针为指定commit，同时重置暂存区，但工作区不变

javascript
$ git reset [commit]
1

7、重置当前分支的HEAD为指定commit，同时重置暂存区和工作区，与指定commit一致

javascript
$ git reset --hard [commit]
1

8、重置当前HEAD为指定commit，但保持暂存区和工作区不变

javascript
$ git reset --keep [commit]
1

9、新建一个commit，用来撤销指定commit

后者的所有变化都将被前者抵消，并且应用到当前分支

javascript
$ git revert [commit]
1

10、暂时将未提交的变化移除，稍后再移入

javascript
$ git stash
$ git stash pop
1
