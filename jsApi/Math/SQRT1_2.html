Math.SQRT1_2 ​

概述

Math.SQRT1_2 属性表示 1/2 的平方根，约为 0.707：

描述 ​

由于 SQRT1_2 是 Math 对象的静态属性，所以应该像这样使用：Math.SQRT1_2，而不是作为你创建的 Math 实例的属性（Math 不是构造函数）。

示例 ​

下面的函数返回 1/2 的平方根：

javascript
function getRoot1_2() {
   return Math.SQRT1_2
}

getRoot1_2() // 0.7071067811865476
