CoinEx 注意事项 ​

信任工作区 ​

强制开启“信任工作区”询问 ​

确保 Cursor 不会自动信任任何新打开的文件夹。

  • 设置路径： Settings -> Features -> 搜索 "Trust" 或进入 Security 相关选项
  • 操作： 确保 Security > Workspace > Trust: Enabled 是勾选状态
  • 效果： 每次打开新项目时，Cursor 必须弹窗询问“是否信任此作者”

严格区分“受限模式”与“信任模式” ​

当你从 GitHub 下载或者克隆一个不完全熟悉的仓库时，永远先选择“不信任（Restricted Mode）”

  • 在受限模式下： AI 仍然可以阅读代码并回答问题，但它无法自动执行终端命令、无法运行项目中的任务（Tasks），也无法调用某些可能导致系统变更的插件
  • 风险点： 文章指出的漏洞通常是在你点击“信任”后，AI 会自动读取项目中的恶意配置文件（如特定的提示词注入），并在你没注意时利用你的信任权限执行 RCE（远程代码执行）

清理已有的“信任列表” ​

你可能在无意中信任了许多不再需要的仓库。

操作：

  1. 按下 Ctrl+Shift+P (Win/Linux) 或 Cmd+Shift+P (Mac)。
  2. 输入并选择 “Workspaces: Manage Workspace Trust”。
  3. 查看 “Trusted Folders & Workspaces” 列表。
  4. 移除所有不常用、或来自外部下载的第三方项目路径。

review 分支 ​

  • 切换功能分支（feature/1113-token-info）
  • 在 Diff Against 那里选择要比较的分支，例如 release/0.4
  • 最后点击 Find Issues
