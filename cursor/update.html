Cursor 特性 ​

核心 AI 交互与编辑能力 ​

全项目级上下文理解（最核心优势）

  • 自动索引整个代码库，理解跨文件依赖、架构、命名规范，不是只看当前文件 Cursor
  • 提问时自动拉取相关代码片段，无需手动粘贴上下文 Cursor
  • 支持 @Codebase 全局问答，直接问 “项目认证流程”“API 调用链”

三大核心模式（Ask/Edit/Agent）

  • Ask 模式（Ctrl+L）：解释代码、查问题、查文档、全局搜索
  • Edit 模式（Ctrl+K）：选中代码，用自然语言直接修改、重构、优化、加注释
  • Agent 模式（默认）：AI 自主规划、多文件修改、执行命令、自动修复，端到端完成任务

智能代码补全（Tab 补全）

  • 基于全工程上下文，提供多行、整函数、设计模式级补全
  • 自适应你的编码风格，预测光标位置，引导编码流程 Cursor
  • 内置 Cursor-Fast 模型：速度比 GPT-3.5 快 3.5 倍，能力介于 3.5 与 4 之间 Cursor

一键应用与差异预览

  • AI 修改后提供逐词高亮差异，一键接受 / 拒绝，支持批量更新
  • 自动处理 lint 错误，迭代修复直到代码规范 Cursor

工程化与协作特性 ​

Cursor Rules（项目 AI 规范）

  • 用 .cursorrules 文件定义项目专属规则：命名、架构、注释、技术栈、禁止模式
  • AI 严格遵循规则生成代码，保持团队一致性，相当于给 AI 一份 “项目说明书”

Git 深度集成

  • 自动生成高质量提交信息，基于代码变更内容
  • 一键解决合并冲突（Resolve in Chat）
  • 分支对比、Bug 扫描、自动生成 PR 描述

自定义与扩展

  • 完全兼容 VS Code 插件、快捷键、配置，一键迁移 Cursor
  • 自定义 Slash 命令、快捷键、布局、AI 行为 Cursor
  • MCP（Model Control Protocol）：连接外部模型、工具、数据源 Cursor

团队与企业能力

  • 团队共享规则、命令、插件、Agent 配置 Cursor
  • 权限管理、审计日志、企业级安全与 SSOCursor
  • 私有化部署、离线模式、数据不用于训练 Cursor

内置工具与环境能力 ​

内置终端与命令执行

  • AI 可自动编写并运行终端命令，默认需用户确认 Cursor
  • 沙箱终端（GA）：安全执行脚本、测试、构建，不污染本地环境

内置浏览器（Browser）

  • AI 直接操作 Chromium，运行前端、测试 UI、截图、录制视频
  • 点击页面元素定位到源代码，所见即所得调试

多模型支持与切换

  • 内置 GPT-4、Claude 3.5、Gemini、Composer、Cursor-Fast 等
  • 智能切换最优模型，平衡速度、成本、能力 Cursor

安全与隐私 ​

  • 本地优先：默认本地处理代码，敏感项目可完全离线
  • 隐私模式：代码不用于模型训练，企业级数据加密 Cursor
  • 沙箱隔离：命令、浏览器、Agent 均在隔离环境运行

其他实用特性 ​

  • 语音编程：语音转文本，用语音控制编辑、提问、执行
  • BugBot 自动修复：扫描代码、检测错误、一键修复，支持 PR 自动合并 Cursor
  • Memories（记忆）：AI 记住项目上下文、历史对话、偏好设置 Cursor
  • Automations（自动化）：按计划 / 事件触发 AI 任务，持续运行、学习优化 Cursor
  • 多语言界面：支持中日韩等 15+ 语言 Cursor

常用快捷键速览 ​

  • Ctrl+L 全局 Chat（Ask）
  • Ctrl+K 内联 Edit
  • Ctrl+. 呼出 Agent
  • Tab 接受补全
  • @Codebase 全局问答
  • @文件/函数 引用代码上下文
